🖥️ Local desktop utility · macOS · FTS / Cursor power users

Token Monitor is a floating always-on-top widget plus details dashboard that aggregates usage across Cursor, Codex, Claude Code, Copilot, and more. It runs entirely on your machine—🔒 SQLite + Keychain—so you can coach yourself on model choice, ticket focus, and burn rate without waiting for a vendor invoice.

  • ⭕ Live usage rings & projected month spend (widget + menu bar)
  • 🎫 Per-run costs with Jira ticket/task + turn adequacy scoring
  • 📈 Cursor breakdowns: rings, pie, trends, avg $/run
  • 🧠 Offline Advice — routing hints, no extra API spend
  • 🔄 Background sync from logs + optional provider APIs
  • ⚙️ Settings: billing anchor, plans, keys, save & sync

Offline Advice — know when to downshift models

The Advice tab analyzes your billing-cycle runs locally—🚫 no Cursor agent, no cloud LLM. It surfaces patterns where premium models met mechanical prompts and where fast/Composer-class would’ve been enough.

  • 🏋️ Heaviest tickets — top 6 by tokens, title, $, model, Jira links
  • ⚡ TL;DR routing — fast vs mid/premium for this cycle
  • 📋 Spend concentration, downgrade candidates, habits

🚀 Productivity: Stops “Opus for lint” before it becomes a habit. One refresh replaces vibes with a coaching brief.

Usage details — tickets, adequacy, cost

Every run maps to a user prompt. Ticket / task pulls Jira keys from prompts or chat threads (🔗 click → Jira). Adequacy scores the turn in context—not just word count.

  • 💰 Sort by cost, recency, or model
  • 🔍 Filter provider + model; resizable columns
  • ✅ Adequacy + role: kickoff, steer, approve, mech, recovery
  • ↩️ Thread inheritance for “continue” / “tpr”

🚀 Productivity: Spend ties to real tickets, not mystery threads. Weak kickoffs get flagged before they multiply.
